# Minds Slice 10 ("She sounds like herself") Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:test-driven-development for every task (test first, see it fail, implement, see it pass). Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** A character the user has given a voice can be heard: tap a reply and it is spoken in her voice, in the tone she shows (a hurt reply quieter and slower, an excited one quicker), with a pause before it and, sparingly, the sigh or laugh her own `*sighs*` asked for. The words never change: a speech tag is never seen in the chat. A reply heard once replays for free. Voice is off until the user turns it on and names a voice model; a failed or missing voice only means no audio.

**Architecture:** A new pure-ish module `speech.py`: `on` (is this character voiced?), `strip` (bracket/angle tags out of the visible reply, kept as tags), `cue` (per-line cue from code: shown mood → tone and intensity, pause, speed, one tag at most from her own action or the side call), `speakable` (what is actually said: quoted speech in prose, the whole text in chat, actions out, the tag rendered for the engine), and `render` (the cache: a key from the spoken text, voice and model; audio saved as content-addressed media; the message's `gen.voice.audio` maps key → file). `LLM.speech` is the one TTS adapter: OpenAI-compatible `POST {base}/audio/speech` (OpenAI, Together, Kokoro-FastAPI, Orpheus-FastAPI, any local server of that shape), usage recorded as characters with role `voice`. A new role `voice` (never inherits). The side call (`after.py`) gains an optional `voice` field (tone, tag) when the speaker is voiced and the level has a side call. `turns._generate` strips tags before saving and sends `done.voice` (the cue). `POST /messages/{id}/voice` renders or replays. Gated by `mind.voice` (alpha), the `voice` role, and `voice.on` (setting, default false; a character's `data.voice.on` wins).

**Tech Stack:** Python 3.12, stdlib only, pytest with the scripted `FakeBackend`.

**Spec:** `docs/specs/2026-09-29-minds.md` §4 (hosted voice is credits-only), §6, §7 slice 10 row, §8.3 (Task 1 writes the contract), §9. Design source: note 18 §1 (licences), §6 (cue, tags stripped, frequency guardrails), §7 (GPU sharing), §8 (stack); note 22 §2 step 12 (voice-render fields in the side call when voice is on); note 21 §3 (voice cost).

## Decisions this plan makes (and why)

- **Audio on request, never in the turn.** The turn only adds the cue to `done` (no call, no wait); the UI asks `POST /messages/{id}/voice` when it wants sound (auto-play or a tap). A voice failure cannot break a turn or lose a reply because it is not in the turn. Skip/stop is the player's: the engine never plays anything.
- **One adapter, OpenAI's `/audio/speech` shape.** It covers cloud TTS (OpenAI, Together's Kokoro/Orpheus) and every local server the research names (Kokoro-FastAPI, Orpheus-FastAPI). The in-process Kokoro adapter is **deferred**: `kokoro` needs torch (~2 GB), and `kokoro-onnx` (MIT) pulls `phonemizer` and `espeakng-loader`, both GPL-3.0 (espeak-ng); neither is "small and permissive". Local Kokoro = a Kokoro server on this machine, pointed at by the `voice` role (the live check ran exactly that).
- **The cue is code's; the side call may refine it.** Tone follows what she *shows* (a masked hurt is spoken calm, as the register does): calm→neutral, content/fond/relieved→warm, glad/amused→cheerful, excited/surprised→excited, anxious/afraid/ashamed→anxious, sad→sad, hurt→hurt, annoyed→cold, angry→angry, bored→flat. Intensity (1–3) from the mood's own "a little"/"very". Pause before speaking and speed per tone (sad and hurt slower with a longer pause, excited/angry/anxious quicker), times the character's own `data.voice.speed`. On standard/premium, when she is voiced, the side call also labels `voice: {tone, tag}` from closed lists and they win. Nothing reaches the reply prompt: no new RULES line, nothing in the cached block, words never numbers anywhere a model reads.
- **Tags: at most one per line** (note 18 §6: sparing). From her own single-word action (`*sighs*`, `*laughs softly*`, `*chuckles*`) where it stands, else the side call's tag at the start. Rendered per the role's `tags` param: `text` (default, Kokoro: laugh "Ha!", chuckle "Heh.", sigh "Hah...", gasp "Oh!", groan "Ugh.", hum "Hmm."; sniff dropped), `brackets` (`[laugh]`: Chatterbox, ElevenLabs v3), `angle` (`<laugh>`: Orpheus). A `[laugh]`/`<sigh>` tag the model itself wrote in the reply is stripped from the saved text when she is voiced and kept in `gen.voice.tags`.
- **What is spoken:** in prose (the reply has a double-quoted span) only the quoted speech; otherwise the whole reply minus `*actions*`/`_actions_`. Nothing left → 422, no call.
- **Cache:** key = SHA-256 of (spoken text, voice, speed, instructions, model, base URL). Audio saved with `media.save` (content-addressed, beside the images), served by `GET /media/{name}`. `gen.voice.audio` maps key → file, at most four per message (another voice, an edited line). Same key and the file present → no call, `cached: true`.
- **Instructions:** a role param `instructions: true` sends a sentence in words ("Speak quietly, a little hurt.") for instruction-following TTS (gpt-4o-mini-tts); off by default (other servers may refuse it).
- **Metering:** the adapter reports `{"prompt_tokens": <characters>}` to `on_usage` with role `voice` (TTS is priced per character), so desktop spend and online billing see it; online, hosted voice is credits-only (§4), enforced by the host's gate (track B3), not here.
- **GPU:** no GPU lease exists in the engine: app images are drawn on HuggingFace (`images.py`, remote) and the engine loads no model on the GPU. TTS here is remote or a separate local server, so the engine cannot put TTS and diffusion on the GPU together. Rule for whoever runs a local TTS server beside a local image spike: run Kokoro on CPU (note 18 §7); never a GPU TTS while a diffusion run holds the card (docs/images/rules-and-gotchas.md). A lease is owed with the first in-engine GPU job.
- **Off by default, every level.** Lite gets voice only when configured (cue from code, no side call).

## Global Constraints

- Commands from `engine/`: `uv run pytest -q`; `uv run ruff check . && uv run ruff format --check .`.
- No new dependencies, no migration.
- Voice never breaks a turn: every new step in the turn is guarded.
- Words, never numbers, in anything a model reads. Nothing new in the cached system block.
- Every tuning constant is marked `ponytail:`. Commit after every task on `feat/minds-slice-10`; never push.
