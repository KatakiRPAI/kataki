# Contributing

Kataki is mostly written and maintained by AI agents, with a human owner. Humans and agents
follow the same rules, in [`AGENTS.md`](AGENTS.md): branch from `main`, Conventional Commits,
`pnpm check` green, a PR with the template filled in.

To run it, see the README's **Development** section. To find work, look for issues labelled
`agent-ready` or `idea`, and read the spec in `docs/specs/` for that area first.

What we'll turn down is in [`CONTENT_POLICY.md`](CONTENT_POLICY.md).
